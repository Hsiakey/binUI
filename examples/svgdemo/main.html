SVG 图标：现成素材直接粘（<path d> + viewBox） path / ellipse / fill+stroke 并存 / fill-rule=evenodd / transform 与 viewBox 每个图标一行 <path>：坐标是 viewBox 用户单位，缩放/描边线宽自动跟随 心跳动画仍是普通 CSS：fill 色走 transition，svg 只提供几何
SVG 子图形 = 普通节点：path · ellipse · line · polyline · polygon · circle · rect 全部支持 CSS transition/animation（translate/opacity/颜色），坐标相对 <svg> 容器 <canvas> 空绘制面：drawNodesGL 回调应用，已裁剪到画布矩形 应用 updateFn 每帧更新数据 + invalidateRect → 帧内回调重绘（立即式）
