按钮样式一览
① 语义色：一套颜色管一类动作
② 尺寸（11 / 12 / 14px）与图标按钮
③ 圆角：2 / 9 / 16 / 胶囊
④ 底色：纯色 / 渐变 / 描边 / 幽灵 渐变底悬停只缩放、不改底色（background-image 不参与过渡）
⑤ 状态：:hover / :active / :checked / disabled 「选中」由外壳调 setNodeChecked 维护；禁用按钮整体变暗并退出 Tab 焦点链 同时命中时的优先级：:active > :focus > :checked > :hover 键盘 Enter / Space 触发的也是同一个 CLICK 事件
⑥ 形态：图标按钮 / 纯文本按钮 / 键盘焦点 / 块级整行
最后点击：— 点击次数 0 WASD 移动焦点　·　方向键滚页面　·　Enter 或 Space 触发　·　Esc 退出
