组件化：二进制内联 / 源码内联 / 运行期外挂
① 源码组件（.bum.xml，可传参） 文本/颜色走 label / bg 参数；自带 :hover 过渡。
② 二进制组件（.bum，编译期内联） 链接器把 card.bum 的节点合并进宿主：节点 id 重编号、字符串表后移、 规格/状态/动画段一起迁移 —— 合并后仍是一棵普通节点树。
③ 三种形态，可以混放 文件：main.html → main.bui（单文件）；组件可放 titlebar.bum（二进制）或 button.bum.xml（源码），也可都放。
优先级：二进制优先；源码 mtime 更新则改用源码并告警 —— 改源码保存即热重载。
外挂：<use src="dock.bum" external> 只留占位，运行期 ex::MountAll() 挂上（见底部）。
